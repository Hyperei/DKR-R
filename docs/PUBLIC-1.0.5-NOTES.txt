DKR-R v1.0.5 Public Build
Windows x64 and Linux x64 AppImage

There's been a lot going on since the last update! Custom tracks and characters,
Track Lab, texture priorities, host-managed online mods, save protection and
the shared launcher/overlay are all part of this build.

Auto selects Experimental Rollback. Host Prediction and Strict Input Sync stay
available. Use the same complete package on every peer, including libexec workers.
Genuine rollback remains experimental, with documented local scenery/category
mixing limits; the version name is not a promise of bug-free netplay.

PR #49 contributes macOS source/build support, portable ELF verification,
dependency/setup recovery, platform lifecycle work and ultrawide sky motion.
No newly qualified macOS binary is included in this delivery.
PR #50 contributes the optional offline Modern camera/F7 tuning panel and
Track Lab geometry/texture improvements. Camera state is reset at handoff and
disabled online. Texture remapping uses recoverable multi-file replacement.

Reviewed legacy behaviour adapters work offline and online for admitted content.
Unknown ROM code/global-data changes still need their own adapters.
Clients consent to host requirements, reuse matching local content, receive only
missing files and can retain verified mods inactive for offline play.
No ROM or personal save collection is shared.

Keep backups of saves and Track Lab projects before updating.
This desktop delivery does not replace the separate Android/ARM previews.
No ROMs, personal saves or sample mods are included.

Current guides: https://github.com/ThatGuyMcd/DKR-R/tree/main/docs
Changes: https://github.com/ThatGuyMcd/DKR-R/blob/main/CHANGELOG.md

user-led; see the validation record for the exact source and package hashes.
