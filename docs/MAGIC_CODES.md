# Magic Codes

Magic Codes stay in **Mods / Hacks → Magic Codes**. Choose the modifiers you
want before launching; conflicting codes are turned off according to the
original game's rules. Codes are launch settings, not a patch to your ROM.

The running game uses a frozen selection. Changes in the UI are for the next
launch, and selection is locked while an online lobby owns the rules.
Online peers must agree on the host's gameplay/Magic Code selection.

## Adventure and one-shot actions

JOINTVENTURE enables the original shared two-player Adventure arrangement.
It does not add three/four-player Adventure. See [Online](ONLINE_MULTIPLAYER.md)
for ownership through hub/boss transitions.

One-shot actions are queued and acknowledged through their native game path.
They are not all treated as permanent EEPROM cheats. Allow ordinary saving
to finish before quitting after an action that awards progress.

For personal save editing, use [Save Manager](SAVES.md), not a guessed code
or manual EEPROM change. The older [Magic Code repair report](MAGIC-CODES.md)
retains the technical injection/queue history.
